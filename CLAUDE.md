# TeacherOS Web

React + Vite Client für TeacherOS, inklusive Capacitor-Hülle für iOS/Android (`capacitor.config.ts`, ADR 0006).

## Agent skills

Issue-Tracker, Triage-Labels und Domänendoku (Glossar, ADRs, Source of Truth) liegen zentral im Repo `teacheros-api` (lokal `../teacheros-api`). Siehe dort `docs/agents/issue-tracker.md`, `docs/agents/triage-labels.md` und `docs/agents/domain.md`. Tickets für dieses Repo tragen das Label `repo:web`.
